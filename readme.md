# Placement Probability Predictor API & Analytics Dashboard

An end-to-end Machine Learning web application designed to process complex student academic profiles and evaluate employment readiness. Moving away from rigid rule-based matrices, this platform utilizes an asynchronous FastAPI backend to query a robust machine learning pipeline, streaming real-time statistical inference straight to a high-fidelity Tailwind CSS analytics dashboard.

## 🚀 Core Capabilities
* **True Machine Learning Engine:** Integrates a pre-trained `RandomForestClassifier` pipeline capable of interpreting structural patterns across multiple data dimensions simultaneously.
* **Production-Grade Architecture:** Deploys a REST API using Python's FastAPI framework optimized with rigorous structural payload filtering using Pydantic schemas.
* **Asynchronous Web Execution:** Communicates instantly via non-blocking JavaScript Fetch API architectures across Cross-Origin Resource Sharing (CORS) security mechanisms.
* **Dynamic Analytics UI:** Computes data visualizations instantly—featuring dynamic SVG radial gauges, adaptive career recommendation tracks, and custom canvas-to-PDF compilation rendering via `html2pdf.js`.

## 🛠️ Technology Stack
* **Frontend UI Layout:** HTML5, Tailwind CSS Engine, Vanilla JavaScript (ES6 Modules)
* **Backend Framework:** Python 3, FastAPI Core, Uvicorn (ASGI Server), Pydantic v2
* **Data Science & Analytics Serialization:** Scikit-Learn, Pandas, NumPy, Joblib
